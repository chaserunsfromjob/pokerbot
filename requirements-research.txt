# What this project's own tests need, and nothing else.
#
# Kept separate from `requirements-vendor.txt`, which is the dependency set that
# makes the reference engine in `vendor/poker_ai` run. Installing both into one
# `.venv` is fine; they do not disagree.
#
# `bin/gate.sh` installs this file into `.venv` when any of the three is
# missing, so the gate never runs against a half-built environment.
#
# open_spiel: the engine. Every rule, every legal move, every hand ranking and
#   every payout comes out of its `universal_poker` game, which is CLAUDE.md's
#   forefront rule. Imported as `pyspiel`.
# pytest: the test runner the suite is written for.
# treys: the outside hand evaluator. Tests only -- it checks that the engine's
#   showdown is right, and never takes part in play.
#
# Versions are the ones installed in the checkout these were verified in, on
# Python 3.13.15, macOS 15.2 (24.2.0), Apple M4.
open_spiel==2.0.2
pytest==9.1.1
treys==0.1.8
